## エラーの原因候補と確かめ方（IE）

### IE-01 Uncaught TypeError: Cannot read properties of null (reading 'value')

- エラーの文章：Uncaught TypeError: Cannot read properties of null (reading 'value')
- 原因の候補：

    1. getElementById に渡した名前が、画面の欄の id と違う
    2. スクリプトが、画面の欄ができる前に動いている

- 確かめ方：

    1. エラーの行に出てくる名前で、HTMLの中を検索し、同じ id の欄があるか確かめる
    2. script の位置が </body> の直前にあるか確かめる

- 状態：直った
- もとになった項目：IP-01

### IE-02 Uncaught SyntaxError: Unexpected token '<'

- エラーの文章：Uncaught SyntaxError: Unexpected token '<'
- 原因の候補：

    1. JavaScriptのファイルの代わりに、HTML（「見つかりません」の画面など）を読み込んでいる
    2. script の src のファイル名が違う

- 確かめ方：

    1. 開発者ツールのネットワークの欄で、そのファイルの中身がHTMLになっていないか確かめる
    2. src のファイル名と、置いたファイルの名前を見比べる

- 状態：原因が分かった
- もとになった項目：IP-02
